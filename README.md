# ניתוח קבצי אקסל חודשיים

אתר לניתוח קבצי אקסל חודשיים עם חיבור ל-Google Sheets.

## תכונות

1. **העלאת קבצי Excel** - העלה קובץ Excel חודשי לעיבוד
2. **סיכום לפי סוג תנועה** - סיכום סכומים לפי עמודה G
3. **סיכום עמלות** - סיכום עמלות לפי עמודות O+P+Q
4. **סיכום תמיכות לפי קטגוריות** - סיכום תמיכות עם קטגוריות מ-Google Sheets
5. **עדכון קטגוריות** - עדכון קטגוריות חסרות ישירות מהאתר
6. **גרפים** - הצגת נתונים בגרפים (Bar Charts ו-Pie Charts)
7. **הורדת קבצי Excel** - ייצוא סיכומים לקבצי Excel מפולחים לפי קטגוריות וסוגי פעולות

## התקנה

### דרישות מקדימות
- Node.js (גרסה 16 ומעלה)
- npm או yarn

### שלבי התקנה

1. **התקן את התלויות:**
```bash
npm install
```

2. **צור קובץ `.env` והוסף את מפתח ה-API של Google Sheets:**
```
VITE_GOOGLE_SHEETS_API_KEY=your_api_key_here
```

3. **הפעל את השרת:**
```bash
npm run dev
```

האתר יעלה על `http://localhost:3000`

## הגדרת Google Sheets API

### לקריאה בלבד (קריאת קטגוריות)

1. לך ל-[Google Cloud Console](https://console.cloud.google.com/)
2. צור פרויקט חדש או בחר פרויקט קיים
3. הפעל את **Google Sheets API**:
   - לחץ על "APIs & Services" > "Library"
   - חפש "Google Sheets API"
   - לחץ על "Enable"
4. צור מפתח API:
   - לחץ על "APIs & Services" > "Credentials"
   - לחץ על "Create Credentials" > "API Key"
   - העתק את המפתח והוסף אותו לקובץ `.env`:
     ```
     VITE_GOOGLE_SHEETS_API_KEY=your_api_key_here
     ```

### לכתיבה לגוגל שיטס (שליחת שורות חסרות)

**⚠️ חשוב:** כתיבה דורשת OAuth2 או Service Account. API Key לבד לא מספיק!

**פתרון מומלץ: Google Apps Script (הכי פשוט)**

ראה קובץ **`SETUP_SERVICE_ACCOUNT.md`** למדריך מפורט.

**קיצור דרך:**
1. פתח את הגיליון שלך ב-Google Sheets
2. לחץ **Extensions > Apps Script**
3. הדבק את הקוד מ-`SETUP_SERVICE_ACCOUNT.md`
4. לחץ **Deploy > New deployment > Web app**
5. העתק את ה-URL והוסף ל-`.env`: `VITE_GOOGLE_APPS_SCRIPT_URL=your_url`

**או:** שתף את הגיליון עם Service Account email (Editor) - ראה `SETUP_SERVICE_ACCOUNT.md` לפרטים

## שימוש

1. **הזן את ה-ID של הגיליון האלקטרוני ב-Google Sheets:**
   - פתח את Google Sheets שלך
   - העתק את ה-ID מהקישור (החלק בין `/d/` ל-`/edit`)
   - לדוגמה: בקישור `https://docs.google.com/spreadsheets/d/123456789/edit`
     ה-ID הוא `123456789`

2. **העלה קובץ Excel חודשי:**
   - לחץ על "בחר קובץ Excel"
   - בחר את הקובץ החודשי שלך
   - לחץ על "עבד קובץ"

3. **צפה בסיכומים:**
   - **טאב 1 - סיכום לפי סוג תנועה:** גרף ותמונה של סיכום לפי עמודה G
   - **טאב 2 - סיכום עמלות:** סיכום עמלות לפי עמודות O+P+Q
   - **טאב 3 - סיכום תמיכות לפי קטגוריות:** סיכום תמיכות עם קטגוריות מ-Google Sheets

4. **עדכן קטגוריות חסרות:**
   - בטאב "סיכום תמיכות לפי קטגוריות"
   - לחץ על אייקון העריכה ליד שורה ללא קטגוריה
   - הזן קטגוריה ושמור

5. **הורד קבצי Excel:**
   - לחץ על כפתור "הורד Excel" בכל טאב
   - ניתן להוריד סיכומים כלליים או קבצים מפולחים לפי קטגוריה/סוג תנועה

## מבנה הקובץ

האתר מצפה לקובץ Excel עם המבנה הבא:

- **עמודה A (ראשונה):** מספר זהות - למציאת קטגוריות
- **עמודה B (שנייה):** תאריך התנועה - למציאת קטגוריות
- **עמודה G:** סוג התנועה - לסיכום לפי סוג
- **עמודה D (או עמודת "סכום"):** סכום התנועה - לסיכומים
- **עמודות O, P, Q:** עמלות - לסיכום עמלות

**הערה:** המבנה המדויק יתאים לקובץ שתתן לנו. נבדוק את הקובץ ונעדכן את הקוד בהתאם.

## פתרון בעיות

### שגיאת "לא ניתן לקרוא את Google Sheets"
- ודא שמפתח ה-API תקין
- ודא שה-ID של הגיליון נכון
- ודא שהגיליון משותף עם כל אחד (או עם החשבון של מפתח ה-API)

### הקובץ לא נטען
- ודא שזה קובץ Excel (.xlsx או .xls)
- ודא שהקובץ לא פגום
- בדוק את הקונסול לדיווח על שגיאות

### קטגוריות לא מופיעות
- ודא שהוזן ID של Google Sheets
- ודא שבגיליון יש עמודות: מספר זהות, תאריך, קטגוריה
- ודא שהתאריכים בפורמט שניתן לזיהוי
